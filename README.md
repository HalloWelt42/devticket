# devticket

Dieses Repository dient als zentrale Anlaufstelle für **Tickets und Kontaktaufnahme**.

## Zweck

- **Fehlerberichte (Bug Reports):** Probleme und Fehler können hier als Issue gemeldet werden.
- **Feature-Anfragen:** Neue Funktionswünsche und Verbesserungsvorschläge können hier eingetragen werden.
- **Kontaktaufnahme:** Allgemeine Anfragen und Kommunikation mit dem Entwickler/der Entwicklerin.

## Wie ein Ticket erstellen?

1. Klicke oben auf den Reiter **„Issues"**.
2. Klicke auf **„New issue"**.
3. Beschreibe dein Anliegen so genau wie möglich:
   - Was ist das Problem oder der Wunsch?
   - Welche Schritte führen zum Problem (bei Fehlern)?
   - Was hast du erwartet und was ist stattdessen passiert?
4. Klicke auf **„Submit new issue"**.

## Hinweise

- Bitte prüfe vor dem Erstellen eines Tickets, ob ein ähnliches Issue bereits existiert.
- Halte Beschreibungen klar und verständlich.
- Dieses Repository enthält keinen Quellcode – es dient ausschließlich der Kommunikation und Ticketverwaltung.
